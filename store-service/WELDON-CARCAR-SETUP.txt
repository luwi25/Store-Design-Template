Weldon Carcar setup

1. Run add-weldon-carcar.sql in the existing Supabase SQL Editor.
2. Add WELDON_CARCAR_PASSWORD to Edge Function Secrets (at least 12 characters).
3. Redeploy store-service/index.ts to the existing quick-handler function.

Keep all existing store passwords. This addition does not enable Weldon sales sync.

This SQL includes notification inbox and IP forwarding for Lark. No separate notification SQL is needed.
