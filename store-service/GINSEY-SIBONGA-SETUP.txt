Ginsey Sibonga setup

1. Run add-ginsey-sibonga.sql in the existing Supabase SQL Editor.
2. Add GINSEY_SIBONGA_PASSWORD to Edge Function Secrets (at least 12 characters).
3. Redeploy store-service/index.ts to the existing quick-handler function.

Keep all existing store passwords. This addition does not enable Ginsey Sibonga sales sync.

The SQL now covers both Front and Back. If you ran the Front-only setup, rerun add-ginsey-sibonga.sql. Keep the same password secret.
