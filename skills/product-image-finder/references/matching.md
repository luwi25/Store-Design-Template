# Match identity separately from quality

Preferred sources: approved local library, exact SKU catalog photo, manufacturer, authorized supplier, then other listings. A source label alone does not prove correctness. Record the page containing the item and any exact model/variant evidence.

Compare brand, model, dimensions/capacity, color, pack quantity, connector/handle shape, accessory count, and packaging. For example, a 20 L box and a 30 L box with the same lid are different products. Multiple objects in the source photo must match what the advertised price includes.

Keep identity evidence and quality notes separate. Identity: exact model confirmed, likely match with specified uncertainty, or unresolved. Quality: pixel dimensions, readable labels, complete product edges, background, watermark, and compression. Large square photos are only quality candidates. If a vision model is available, use it to compare visible attributes and detect conflicts; do not interpret a self-reported confidence percentage as a calibrated probability.

Reject mismatched models, misleading accessory bundles, obstructive overlays, and illegible identifying details. Prefer authorized supplier photos or user photos; do not erase ownership watermarks to make an unsuitable source usable. Record source/use information when supplied, and mark it unknown when not established.

If descriptions are generic and no product reference exists, request an actual product photo or present candidates for review. A missing photo is an unresolved task, not permission to substitute a similar item.

Product identity is store + product ID in the library; retain stock code as metadata. Products shared by several slots use the same approved asset without changing slot settings.
